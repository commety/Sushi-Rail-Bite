# Skill: /task-done (Task Completion)

코드 수정이 끝나면 반드시 이 마무리를 수행한다. **코드를 수정하고 세션을 끝내는 것은 반쪽짜리 작업이다.**

---

### STEP 1 — 변경 사항 요약

- 수정한 파일, 변경한 심볼, 추가/삭제 라인 수를 나열한다.
- 의도한 변경과 실제 변경이 일치하는지 확인한다.
- **의도하지 않은 변경이 있으면 즉시 보고한다.**

---

### STEP 2 — 자체 검증

**불변 제약 (RULES.md)**
- [ ] 신규 이벤트 구독이 있다면 → `OnDestroy()` / `OnDisable()`에서 해제 쌍이 존재하는가
- [ ] `async` 메서드가 있다면 → `CancellationToken`이 인자로 전달되는가 (RULE-05)
- [ ] `static` 변수를 추가했다면 → `[RuntimeInitializeOnLoadMethod]`로 초기화하는가
- [ ] 에디터 전용 코드가 있다면 → `#if UNITY_EDITOR` 또는 에디터 어셈블리 아래에 있는가
- [ ] 물리 API 호출이 `FixedUpdate`에 있는가 (RULE-04)
- [ ] RULES.md 전 규칙 위반이 없는가

**이 프로젝트의 아키텍처 규약 (`CLAUDE.md` §3~§4)**
- [ ] 밸런스 수치(가격·집기 범위·먹는 속도·포화도·소화 시간·목표 매출)가 코드 상수로 새어 들어가지 않았는가 — 전부 SO 필드인가
- [ ] 새 로직이 `MonoBehaviour` 안이 아니라 EditMode 테스트 가능한 순수 C# 클래스에 있는가
- [ ] 벨트 위 초밥 생성/반환이 `SushiPool` 을 경유하는가 (`Instantiate`/`Destroy` 직접 호출 없음)
- [ ] 네임스페이스가 `SushiDefense.<Domain>` 이고 폴더/어셈블리와 일치하는가
- [ ] 어셈블리 의존이 단방향인가 (`Runtime` 이 `Presentation` 을 참조하지 않음, 프로덕션이 `Tests.*` 를 참조하지 않음)
- [ ] `Update()` 안에 새 할당이 생기지 않았는가 (WebGL — GC 히칭 직결)

---

### STEP 2.5 — 커밋 전 체크리스트 (`CLAUDE.md` §8)

**커밋을 만들기 전에 전부 통과해야 한다. 하나라도 실패하면 커밋하지 말고 실패를 보고한다.**

체크리스트 1~4번은 **명령 하나로 돈다.** 하나가 실패해도 멈추지 않고 끝까지 돌아 표로 보고하므로, 고치고 다시 돌렸더니 다음 게 터지는 왕복이 줄어든다.

```bash
./tests/preflight.sh
```

| 항목 | preflight 가 하는 것 | 개별 실행 |
|---|---|---|
| 1. 포맷/린트 | `.editorconfig` 기준 검사 | `./tests/lint.sh` (`--fix` 로 수정) |
| 2. 컴파일 | 테스트 실행 중 확인 — **컴파일 실패는 종료 코드 2** 로 테스트 실패(1)와 구분된다 | `./scripts/bridge-run.sh` |
| 3. 테스트 | EditMode 전량 | `./tests/run-tests.sh` (`all` 이면 PlayMode 포함) |
| 4. 에셋 유출 (`CLAUDE.md` §9) | 원본 확장자 스테이징 여부 + RULE-03/06 | `git status --short` |

- **`Unity -batchmode -runTests` 를 손으로 조립하지 않는다.** `Unity` 는 PATH 에 없고, 손으로 치면 `-quit` 을 붙이게 되는데 그러면 테스트가 끝나기 전에 에디터가 내려간다.
- **`exit 4`(에디터 점유)** 가 나오면 ClaudeBridge 용 에디터가 떠 있는 것이다. 배치모드는 프로젝트 락을 단독으로 잡는다.
- 원본 에셋이 걸리면(`warn`) "최종/공개용이 맞는지" 사람에게 **반드시 확인받고** 진행한다. 에이전트가 단독 판단하지 않는다.

5. **신규 로직에 대응 테스트가 있는가** (`CLAUDE.md` §5.4) — 이건 판단 항목이라 자동화되지 않는다. 직접 확인한다.

> `preflight.sh` 는 **테스트 0개를 통과로 보지 않는다**(종료 코드 3). 스위트가 빈 채 Green 이 나오면 게이트가 조용히 무력화되기 때문이다.

> 커밋 메시지는 Conventional Commits (`feat(customer): add digestion cooldown state`). 머지·푸시·브랜치 삭제·PR 머지는 **사람만** 한다 (`CLAUDE.md` §6·§7) — 에이전트는 명령을 제시하고 멈춘다.

### STEP 3 — Lock 해제

- `/task-start` STEP 4에서 Lock을 획득했다면 반드시 해제한다.
- 하네스가 없으면 건너뜀.

---

### STEP 4 — worktree 정리

- 워크트리에서 작업했다면 머지 상태를 확인한다.
- 아키텍트 리뷰 대기 중이면 워크트리를 그대로 둔다.

---

### STEP 5 — 도메인 지식 승격 (Level 2)

이번 세션에서 **이 프로젝트만의** 새로운 것을 알게 되었는가?

승격 대상 예시:
- 기획 의도 ("왜 초밥이 라인 끝으로 흘러가도 실패가 아닌가")
- 시스템 간 유기적 관계 ("손님의 포화도가 차면 그 테이블 구간의 벨트 회전율이 실질적으로 떨어진다")
- 비즈니스 공식 ("매출 = 소비된 초밥 가격의 합 + 시너지 보너스")
- 데이터 흐름 / 이벤트 체인 순서 (초밥 스폰 → 손님 스캔 → 집기 → 포화 → 소화 → 매출 반영)
- 이 프로젝트 고유 용어 — 단, `CLAUDE.md` §2 에 이미 있는 Sushi/Customer/Table/Belt/Deck/Stage/Run 은 제외
- 밸런스 수치의 근거 ("스테이지 2 목표 매출을 8000으로 잡은 이유")

승격 대상이 **있으면**:

1. `.claude/domain/` 아래 기존 파일이 있는지 확인한다 (예: `customer-satiety.md`).
2. 있으면 해당 파일에 섹션 추가, 없으면 [domain/README.md](../../domain/README.md) 템플릿으로 **새 파일 생성 제안**.
3. 파일을 수정했거나 추가했다면 [`.claude/INDEX.md`](../../INDEX.md)의 **Level 2 섹션에 `keywords`도 함께 업데이트** — 그래야 다음 세션의 `/task-start`가 선별 로드 가능.
4. diff 형식으로 제안하고 **아키텍트 승인을 기다린다**. 직접 커밋 금지.

승격 대상이 **없으면**:
- 이 STEP은 "승격 대상 없음"으로 명시하고 건너뛴다. 억지로 만들지 않는다.

> **주의:** 도메인 지식은 `CLAUDE.md`에 누적하지 않는다. CLAUDE.md는 프로젝트 개요·구조·컨벤션을 담고, 시스템/기획 단위 지식은 `.claude/domain/`에 분리한다. 블로그 §3 "나쁜 패턴 2 — 전지전능형" 회피.

---

### STEP 6 — 범용 지식 승격 판단 (/self-update)

다음 조건 중 하나라도 충족되면 `/self-update`를 호출한다:

- 어느 Unity/C# 프로젝트에도 적용되는 **범용 패턴**을 새로 발견했다 → `.claude/knowledge/` 승격 후보
- 기존 지침이 부정확하거나 불완전함을 확인했다
- 반복될 가능성이 높은 실수를 했다 → `RULES.md` 또는 `.claude/rules/` 후보

`/self-update`는 계층 판단까지 수행한다. 이 STEP에서는 호출 여부만 결정.

---

### STEP 7 — 완료 보고

작업 결과를 간결하게 보고한다.

## 금지 사항

- 도메인 지식을 `CLAUDE.md`에 섞어 넣지 않는다. `.claude/domain/`에 분리.
- 도메인 파일을 만들고 INDEX.md 업데이트를 빠뜨리지 않는다. 인덱스가 빠지면 다음 세션에서 발견되지 않는다.
- 아키텍트 승인 없이 도메인 파일을 직접 커밋하지 않는다.
- **STEP 2.5 를 통과하지 않은 상태에서 커밋 메시지를 만들거나 커밋하지 않는다** (`CLAUDE.md` §8).
- **`git merge` / `git push --force` / 브랜치 삭제 / PR 머지 버튼 / `main`·`release/*` 직접 커밋을 에이전트가 실행하지 않는다** (`CLAUDE.md` §6.4·§7). 명령을 제시하고 사람의 승인을 기다린다.
- **원본 에셋(스프라이트·음원)을 확인 없이 커밋하거나 외부(이슈·PR 설명·채팅)에 업로드하지 않는다** (`CLAUDE.md` §9).
