## MVP 마일스톤

### 1차 MVP 목표: 기본 메커니즘 구현 및 검증

- 주요 기능: 초밥을 라인에 배치하는 방법, 기본적인 타워 기능, 타워의 스캔 및 처리 로직
- 목표:
    - 게임이 시작하면 초밥이 라인 시작점에서 나오고 타워를 지정된 위치에 배치할 수 있다
    - 타워는 초밥을 인식하고 처리한다
      - 타워는 기본적으로 먼저 인식 초밥을 먼저 처리하는 FIFO(FCFS) 방식이다

### 2차 MVP 목표: 기능 세부화

- 주요 기능: 초밥 스탯, 타워 기능 세부, 스테이지 제한 요소
- 목표:
    - 초밥은 아래의 정보를 가진다
      - Sequence Number: 동일 우선 순위 처리 시 먼저 도착한 초밥을 처리하기 위함 
      - 가격(점수 및 우선순위 판별 용)
      - 포화도(손님의 포화도 스탯을 채우는 수치)
    - 타워는 초밥을 스캔해서 자신의 우선순위에 따른 초밥을 우선적으로 처리한다
    - 타워는 아래의 스탯을 가진다
      - Sequence Number: 아마 배치 순서에 따른 번호가 될 것, 동일 우선 순위 처리에서 먼저 배치한 손님이 먼저 처리하도록 처리하기 위함 
      - 타겟팅(선호하는 가격대, 여러 초밥 중 우선순위로 집는 것)
      - 집기 범위
      - 먹는 시간
      - 포화도(일종의 체력 개념이며 손님이 계속 초밥을 처리하는 것을 제한하는 요소)
      - 소화 시간(포화도 꽉차면 잠깐 휴식)
      - 영입 비용(설치 비용)
    - 초밥 처리에 대한 규칙
      - 1명의 손님이 2개 이상의 초밥을 인식한 경우 타겟팅에 따라 우선순위를 선정, 이후 동일 우선순위에 대해서 순차번호를 참고해 1개의 초밥을 처리한다
      - 2명 이상의 손님이 하나의 초밥을 동시에 인식한 경우 타겟팅에 따라 우선순위를 선정, 이후 동일 우선순위에 대해서 순차번호를 참고해 1개의 초밥을 처리한다
      - 2명 이상의 손님이 2개 이상의 초밥을 인식한 경우 타켓팅에 따라 우선순위 선정, 순차번호에 따라 순차적으로 처리한다
    - 한 스테이지에 최대 배치 가능 손님 수를 두어 제한한다.
    - 스테이지 시작 시 초반 영입 비용을 제공한다.
    - 영입 비용은 초밥 처리 시 얻는 점수에 `점수/10`으로 획득한다.

### 3차 MVP 목표: 스테이지 클리어 조건과 로그라이트 요소 추가

- 주요 기능: 스테이지 목표, 회차 종료 시 보상 선택, 초밥 시너지 추가
- 목표: 
    - 스테이지 목표를 달성하면 클리어한다
    - 스테이지 종료 시 보상(초밥 카드 추가 또는 손님 영입)을 선택할 수 있다
    - 초밥은 시너지를 가질 수 있다(선택사항)
      - 이 기능을 구현한다면 초밥에 '특성' 또는 '태그' 스탯을 추가해야 한다
      - 시너지가 발생한 해당 초밥을 손님이 처리 시 해당 손님은 일정 횟수/시간 동안 
        - 추가 점수 획득
        - 소화 속도 증가
        - 먹는 속도 증가
        - 느끼는 포화도 감소 등의 버프를 제공한다

### 4차 MVP 목표: 손님 유형 추가, 스테이지 구성

- 주요 기능: 다양한 유형의 손님, 스테이지 클리어 시 다음 스테이지
- 목표:
    - 손님(타워)은 기본, 소식, 먹보 유형으로 나뉜다
    - 기본 손님: 기본 제공 타워, 모든 스탯이 평이하다
    - 소식 손님: 포화도가 적지만 비싼 걸 우선적으로 고른다, 영입 비용이 중간 정도이다
    - 먹보 손님: 먹는 속도가 빠르고 포화도가 높지만 저가를 우선적으로 고른다, 영입 비용이 비싸다
    - 스테이지가 끝나면 다음 스테이지로 넘어간다

### 5차 MVP 목표: UI/UX 및 디자인, 음악 요소 추가

- 주요 기능: 배경, 초밥 라인, 초밥 디자인, 손님 디자인, UI 디자인, 음악 및 VFX
- 목표:
    - 스테이지는 배경과 초밥 라인, 테이블 디자인을 가진다
    - 손님은 각 유형에 맞는 외형과 애니메이션을 가진다
    - 스테이지 시작 시 기본 배경음악이 재생된다
    - 각 행동에 맞는 효과음이 재생된다(볼륨 겹침 문제, 효과음 커지는 문제 고려해야 함)

### 6차 MVP 목표: 게임 시작 화면과 스테이지 진입 이벤트 추가

- 주요 기능: 메인 화면, 키 비주얼 및 테마 일관화, 진입 전 화면 추가
- 목표:
    - 게임은 메인 화면을 가진다
    - 메인 화면에서 스테이지 진입, 백과사전, 튜토리얼, 설정을 볼 수 있다
    - 게임 시작 시 간단한 스토리와 이벤트를 보여준다(선택사항)
    - 설정은 항상 볼 수 있게 헤더 라인에 고정으로 있다
    - 스테이지 시작 전 손님 고르기, 초밥 덱빌딩 화면을 거친다

### 7차 MVP 목표: 게임 전체 흐름 검사 및 테스트

- 주요 기능: 게임 플로우, 게임 실행, 게임 테스트
- 목표:
    - 게임을 진행하는데 있어 매끄러운지 확인
    - 게임을 진행하는데 있어 버그가 있는지 확인
    - 게임 실행 시 문제가 없는지 확인

### 8차 MVP 목표: 배포 및 테스트

- 주요 기능: 웹에 실제로 배포해서 실제 환경에서 테스트
- 목표:
    - 웹 브라우저에서 게임이 정상 동작해야 한다
    - 다른 브라우저도 되는지 검사한다(안되는 경우 명시해야 한다)

### 9차 MVP 목표: QA

- 주요 기능: 게임 플레이하며 발견되는 문제점을 고치고 스테이지 레벨, 손님 및 초밥 밸런싱 수행
- 목표:
    - 게임 플레이하는데 있어 예상 치 못한 버그를 찾기 위해 여러가지 시도해본다
    - 게임 자체의 난이도와 밸런싱 요소를 평가해 반영한다

### 번외(선택사항)

- 기본 기능 구현 후 3-stage Demo가 최종 목표이지만
  시간이 남는다면 보스전이나 방해물, 방해꾼 요소도 추가할 수 있다
- 주요 캐릭터를 타워로 추가할 수도 있다
- 테이블 위치 변경 및 추가하는 기능을 추가할 수도 있다
